## Architecture Overview

This is an **Umbraco 13 CMS solution** (.NET 8) consisting of two main projects:

- **Interon.Roadlab.Web.v13** - Main Umbraco web application project
- **Interon.Roadlab.Web.Net.Core** - Core library containing controllers, models, view models, and shared components

The solution follows Umbraco's standard architecture with:
- **ModelsBuilder** configured for SourceCodeAuto mode, generating models in `Interon.Roadlab.Web.Net.Core/Models/ContentModels/`
- **uSync** for content synchronization between environments
- **Surface Controllers** for form handling (ContactSurfaceController, VacancySurfaceController, etc.)
- **MVC Controllers** for search and other functionality

## Development Commands

### Building the Solution
```bash
# Build entire solution
dotnet build Interon.Roadlab.Web.sln

# Build specific project
dotnet build Interon.Roadlab.Web.v13/Interon.Roadlab.Web.v13.csproj
```

### Running the Application
```bash
# Run the main web application
dotnet run --project Interon.Roadlab.Web.v13

# Or navigate to the project directory
cd Interon.Roadlab.Web.v13
dotnet run
```

### Package Management
```bash
# Restore NuGet packages
dotnet restore

# Add new package to main project
dotnet add Interon.Roadlab.Web.v13 package PackageName

# Add new package to core library
dotnet add Interon.Roadlab.Web.Net.Core package PackageName
```

## Project Structure Details

### Core Components Location
- **Controllers**: `Interon.Roadlab.Web.Net.Core/Controllers/`
  - MvcControllers/ - Standard MVC controllers
  - SurfaceControllers/ - Umbraco surface controllers for form handling
- **Models**: 
  - Generated content models: `Interon.Roadlab.Web.Net.Core/Models/ContentModels/`
  - View models: `Interon.Roadlab.Web.Net.Core/Models/ViewModels/`
- **Configuration**: `Interon.Roadlab.Web.Net.Core/Config/`
- **Views**: `Interon.Roadlab.Web.v13/Views/`
- **Static Assets**: `Interon.Roadlab.Web.v13/wwwroot/`

### Key Dependencies
- Umbraco CMS 13.2.2
- Our.Umbraco.FullTextSearch 4.1.0
- uSync 13.1.3 (content synchronization)
- .NET 8.0

### Configuration Notes
- **Database**: Azure SQL Database connection configured in appsettings.json
- **Email**: SMTP settings for contact forms and notifications
- **ModelsBuilder**: Auto-generates content models in the Core project
- **uSync**: Enabled for content deployment between environments

## Development Workflow

When working with this codebase:

1. **Content Models** are automatically generated by Umbraco's ModelsBuilder in the Core project
2. **Form handling** should use Surface Controllers in the SurfaceControllers directory
3. **Views** follow Umbraco's templating conventions with Razor
4. **Static assets** go in wwwroot/ directory
5. **Content synchronization** is handled by uSync - check uSync folder for serialized content
